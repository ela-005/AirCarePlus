# AirCare+

## Description

AirCare+ is an IoT environmental monitoring system.

The project simulates environmental sensors, sends measurements through MQTT, stores data, and displays them on a dashboard.

## Technologies

- Python
- MQTT
- Git/GitHub
- Streamlit
- CSV Data Logging
